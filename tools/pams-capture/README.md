# PAMS 캡처 — 크롬 확장 (SH10 B안)

네이버 비공개 게시 뒤 사람 손을 **「붙여넣기 → 비공개 발행 → 이 버튼 1번」** 으로 줄인다.

1. `naver_private_guide.py` 서식 html 을 네이버 편집기에 붙여넣고 **비공개**로 발행한다(사람).
2. 그 글 화면에서 확장 버튼을 누른다 → 탭을 텍스트 PDF 로 인쇄해 `Downloads\PAMS접수\<글 제목>.pdf` 로 저장한다.
3. 이후는 기존 자동: `pams_auto`(SHIN_PAMS_KIT, 10분 주기)가 파일명(=네이버 제목)으로 짝을 맞추고,
   `pams_kit` 이 PDF 제목·본문 첫 줄을 원고와 대조한 뒤 zip 키트를 만든다.

## 하지 않는 것
- 글쓰기·발행·공개 전환·클릭 자동화(네이버 자동 게시는 설계에 넣지 않는다 — 실명 계정 정지 위험, 약관 금지 소지)
- 쿠키·비밀번호 읽기, 외부 전송. 사람이 로그인해 연 탭을 그대로 인쇄만 한다.
- `insightlab-daily` 가 아닌 탭은 인쇄하지 않는다.

## 설치 (한 번)
크롬 `chrome://extensions` → 개발자 모드 → 「압축해제된 확장 프로그램 로드」 → 이 폴더.
결과는 버튼 배지로 본다: `OK` 저장 · `!` 저장했으나 화면에서 「비공개」 글자를 못 찾음 · `X` 인쇄 안 함(버튼에 마우스를 올리면 이유).

## ⚠️ 실측 필요(첫 사용 때 1회)
- **비공개 표시가 PDF 에 남는가**(§6.4 「비공개 상태가 화면에 확인되도록 캡처」, 2025-07-14 시행).
  버튼은 화면에서 「비공개」 글자를 못 찾으면 알림으로 경고한다. 남지 않으면 지금의 수동 인쇄도 같은 문제를
  안고 있는 것이므로, 상단 스크린샷을 PDF 첫 장에 덧붙이는 처리를 추가한다.
- PC 화면은 본문이 iframe 안에 있어 본문 주소(PostView)로 같은 탭을 다시 열고 인쇄한다. 이 화면에서도
  비공개 표시가 보이는지 함께 본다.
- 버튼을 누르면 크롬 상단에 「디버깅 중」 띠가 잠깐 뜬다(Page.printToPDF 사용). PDF 에는 찍히지 않는다.
