# 채널별 마케팅 자동화 플레이북 — 신순주의 선한 금융

> 목표: 모든 채널이 각자의 문체와 역할로 트래픽을 모으고, 최종적으로 **본진(웹사이트) → 자산진단 → 리드(전화번호)**로 흘려보내는 단일 깔때기.

## 전체 구조 (One Source, Multi Use)

```
[원천] 금감원 보도자료 · 경제뉴스 (매일 새벽 자동 수집)
   ↓ Claude AI가 채널별 4가지 문체로 동시 변환
   ├─ ① 본진 웹사이트  ─ 자동 발행 (사람 개입 0)
   ├─ ② 네이버 블로그  ─ 원고 자동 도착 → 붙여넣기 1분
   ├─ ③ 구글 블로그스팟 ─ 원고 자동 도착 → 붙여넣기 1분
   └─ ④ 인스타/스레드  ─ 카드뉴스 PNG 자동 생성 → 업로드 2분
                ↓
        모든 채널의 링크 = 본진 /diagnosis (자산진단)
                ↓
        리드 DB + 텔레그램 실시간 알림 → /admin에서 관리
```

| 항목 | 내용 |
|---|---|
| **역할** | 권위의 최종 목적지. 구글 검색 + AI 검색(ChatGPT·Perplexity) 유입 |
| **문체** | 전문가 칼럼체. 진지하고 정확, 소제목·표 활용, 마지막에 "신순주의 한 줄 조언" |
| **발행** | 매일 06:00 자동 (사람 개입 없음) |
| **SEO 장치** | JSON-LD(저자 실명 스키마), sitemap 자동, FAQ 리치 스니펫, llms.txt(AEO) |
| **KPI** | 구글 색인 수 → 3개월 후 자연검색 일 방문자 → 진단 전환율 |

**운영자가 할 일**: 없음. (배포 후 1회: 구글 서치콘솔에 sitemap.xml 제출)

## ② 네이버 블로그 — "친근한 언니/이모 문체"

| 항목 | 내용 |
|---|---|
| **역할** | 대한민국 검색량 1위 채널 공략. 스마트블록 노출 |
| **문체** | 공감 존댓말("~하셨나요?", "저도 상담하다 보면요"), Q&A 소제목, 이모지 절제 |
| **왜 다른 문체?** | 네이버 C-Rank는 '출처의 진정성'을 봄 — 본진과 같은 글을 복붙하면 유사문서로 감점. 완전히 다른 글이어야 함 (AI가 이미 다르게 씀) |
| **KPI** | 스마트블록 노출 키워드 수, 이웃 수, 블로그 → 사이트 클릭 |

**최초 세팅 (1회, 30분)**:
1. 네이버 블로그 개설 (기존 계정 가능) — 블로그명 예: "신순주의 선한 금융 이야기"
2. 프로필에 실명·경력·GA명장 명시 + 사이트 링크
3. 카테고리 5개 생성: 금융뉴스 / 생활경제 / 보상꿀팁 / 판례해설 / 천안소식
4. 대표 인사글 1편 작성 (자기소개 — 이건 직접 쓰시는 게 진정성에 좋음)

**매일 루틴 (1분)**: 텔레그램에 도착한 `naver-*.txt` 열기 → 전체 복사 → 블로그 글쓰기에 붙여넣기 → 카드뉴스 이미지 2~3장 첨부 → 발행. 글 말미에 항상: "무료 자산진단 👉 (사이트 링크)"

**주의**: 하루 1개만. 같은 시간대(예: 아침 8시) 규칙적 발행이 C-Rank에 유리.

## ③ 구글 블로그스팟 — "딱딱한 전문가 개조식"

| 항목 | 내용 |
|---|---|
| **역할** | 구글 롱테일 키워드 쉴드(본진이 못 잡는 세부 키워드 커버) + 백링크 |
| **문체** | 번호·불릿 개조식, 용어와 근거 중심, 감정 배제 |
| **KPI** | 구글 색인 수, 블로그스팟 → 본진 유입 |

**최초 세팅 (1회, 20분)**: blogger.com → 구글 계정으로 블로그 생성 → 제목 "보험·금융 판례 아카이브 by 신순주" → 설정에서 검색 노출 허용 → 프로필에 본진 링크.

**매일 루틴 (1분)**: 텔레그램의 `blogspot-*.txt` 복사 → 붙여넣기 → 발행. 글마다 본진 원문 링크 삽입("전체 해설: 링크").

## ④ 인스타그램 + 스레드 — "훅킹 카드뉴스"

| 항목 | 내용 |
|---|---|
| **역할** | 신규 인지 + 2030~40 여성 타깃 도달. 팔로워를 카톡/진단으로 |
| **형식** | 1080×1350 카드뉴스 8~10장 (자동 생성됨) — 1장 훅, 중간 핵심, 마지막 CTA |
| **문체** | 짧고 강한 한 줄. "보험금 못 받는 사람들의 공통점 3가지" 스타일 |
| **KPI** | 저장 수(가장 중요), 프로필 방문, 링크 클릭 |

**최초 세팅 (1회, 30분)**: 인스타 프로페셔널 계정 전환 → 프로필: "23년차 보험전문가 | 8년 연속 우수인증 | GA명장" + 링크는 `/diagnosis` → 스레드 계정 연결.

**매일 루틴 (2분)**: /admin 콘텐츠 탭에서 카드 이미지 다운로드 → 인스타 캐러셀 업로드(첫 카드 문구를 캡션 첫 줄로) → 스레드에는 카드 1장 + 훅 문장만. 해시태그: #보험 #보험금청구 #재테크 #천안 + 글 주제 2개.

**성장 전략**: 주 1회는 자동 카드 대신 '신순주 얼굴이 나오는 릴스'(예: "오늘 고객이 이런 질문을 하셨어요") — 사람이 보여야 팔로우가 붙습니다.
